## English

Changes since v0.1.0:

- Added a standalone Control Strip button and settings pane with custom symbols, clipboard/text, keyboard shortcut, Shortcuts, URL, and previous/next media actions.
- Added tap, long press, and Option/Command/Control + tap bindings. Fixed physical Touch Bar hold recognition; the duration is configurable and defaults to 0.6 seconds.
- Added Bluetooth connection and system playback automation, ordered rules, combined conditions, and per-configuration visibility. Media state updates through notifications without periodic polling.
- Added Relative/Fixed/Hug button widths in Fill layouts and independent Auto/Fixed/Hug widths for the Text component.
- Reorganized Control Strip settings and expanded live-editing, persistence, and touch regression checks.

Download `TouchBarEnhancer-0.2.0-macOS-arm64.zip`. Requires macOS 14+ and Apple Silicon; hardware use requires a Touch Bar. Keep the app at a stable installation path. Launch is silent by default; configure it through **TB → Settings…**.

The app is signed but **not notarized**; Gatekeeper may block it. Control Strip and media features use private system APIs; skipping depends on the active player's support. The native-to-custom bar slide-in transition remains a known limitation.

Verify the ZIP with the accompanying `SHA256SUMS.txt`:

```sh
shasum -a 256 -c SHA256SUMS.txt
```
